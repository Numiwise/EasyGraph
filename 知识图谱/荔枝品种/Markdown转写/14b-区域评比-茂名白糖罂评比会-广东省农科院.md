# 植保所举办茂名白糖罂荔枝区域评比会_广东省农业科学院

> 来源：`../原始资料/14b-区域评比-茂名白糖罂评比会-广东省农科院.html`

---

白糖罂荔枝，又名中华红，是国家地理标志产品，自古就是历代皇朝的名贵贡品之一，是广东省早熟优质品种，也是茂名市大面积推广种植的品种之一。为了推进茂名白糖罂荔枝标准化生产的进程及其优质安全果品的品牌建设，我院植保所、广东省农业科学院茂名荔枝专家工作站联合国家荔枝龙眼产业技术体系加工研究室、茂名综合试验站和茂名市科学技术协会分别于5月19日和5月23日在茂名市水果试验场培训中心举办了一系列茂名地区白糖罂荔枝区域评比会，邀请业内专家对茂名白糖罂荔枝进行品鉴。
　　本次评比会邀请国家荔枝龙眼产业技术体系首席陈厚彬教授、华南农业大学园艺学院院长胡桂兵教授及体系内部分岗位专家和试验站站长、国家荔枝良种重大科研联合攻关联合体部分成员共30余名专家组成评比小组，促使荔枝领域专家和茂名白糖罂荔枝零距离接触，让专家对茂名地区白糖罂荔枝的品质进行直观评价。通过评比，专家评选出“好看、好吃、好价格”的白糖罂荔枝优质果品，为白糖罂荔枝果品感官评价标准的确定提供基础。同时，让专家对白糖罂荔枝有了较深刻的认知，为该品种的推介提供良好基础。经过专家探讨，一致认为该评比会的召开具有重大意义。在此基础上，植保所将开展以下工作：对参赛果品的常规品质性状（单果重、可溶性固形物含量、焦核率等）和内含物（糖类、有机酸类和氨基酸类等物质）进行测定；对各种植户的产地环境、栽培措施及物候期等进行调研。结合本次评比会的评比结果，综合分析产地环境、栽培措施及物候期等，如何通过对荔枝果品内含物如糖类、有机酸类和氨基酸类等物质的种类、含量与动态变化产生影响，从而对白糖罂荔枝的口感风味造成影响。研究结果为建立完善茂名白糖罂荔枝营养品质评价标准提供理论依据；同时，为推动茂名白糖罂优质安全果品的标准化生产和品牌建设提供数据支撑。
　　本次评比会的成功举办，使专家学者对茂名白糖罂荔枝有了深刻的认知，推动茂名白糖罂标准化生产的进程，促进优质安全茂名白糖罂荔枝品牌的建立；同时，为今后开展其它区域评比会提供借鉴，具有深远的意义。
