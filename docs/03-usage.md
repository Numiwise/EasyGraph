# 使用指南

> 本指南介绍**已部署好的系统怎么用**。如果还没部署，先看 [00-quickstart.md](00-quickstart.md)。

## 三种入口

| 入口 | URL | 用途 |
|------|------|------|
| **Webviz** | http://localhost:5006 | 主页 + 图谱浏览 + AI 问答（用户侧主入口） |
| Neo4j Browser | http://localhost:7474 | 直接看图、跑 Cypher（管理员） |

## Webviz 三页

### 1. 首页（HomeView）

```
http://localhost:5006/
```

- 顶部 hero：标题 + 「向 AI 提问」按钮 + 统计（实体/关系/专题）
- 中间：1 张总图横卡 + 6 张专题矩阵
- **点击任一卡片** → 打开对应子图（GraphView）

### 2. 图谱浏览（GraphView）

```
http://localhost:5006/#/graph/<workspace>
```

例：`/#/graph/g03_varieties`

- 大图谱画布（vis-network）+ 右侧节点详情面板
- **实体类型筛选**：左下图例多选筛选（打钩/全选/全部不选）
- **点击节点**：右侧显示属性 + 邻居关系 + 原文片段
- **悬停节点**：相邻边短暂高亮
- **滚轮缩放**、**拖拽平移**
- 顶部工具栏：切换子图、搜索、进入「智能问答」/「导航」等入口

### 3. AI 问答（QueryView）

```
http://localhost:5006/#/query?ws=g03_varieties
```

- 顶部「新建对话」「历史对话」按钮
- **左侧抽屉**（默认折叠）：所有会话列表（按工作区分组）
- 中央对话区：流式回答 + 行内 `[n]` 引用
- 右侧"走过的子图"：每轮问答后展示关联实体网络
- **悬停 `[n]`**：弹出原文段落（可滚动）
- **点击 `[n]`**：打开原网页（HTML/PDF 直接渲染）

### 4. 原文页（DocView）

通过点击 `[n]` 链接自动打开，无需手动访问。

## 操作小贴士

### 图谱浏览
- **双击节点**：在 GraphView 双击节点聚焦视图
- **点击空白处**：不移动视野（不像一些工具会自动缩放）
- **节点拖拽**：默认禁用（避免误操作）
- **左侧固定边颜色 + 选中节点才加深**：让图谱不"乱"

### AI 问答
- **Shift+Enter**：输入框换行
- **Enter / Ctrl+Enter**：发送
- **切换 ws**：工具栏的"图谱"下拉，换工作区后历史会话会按 ws 切换
- **新建对话**：自动归档当前 + 开空白

### 多工作区切换（PowerShell）

```powershell
# 启动某个分图（以 g03 为例）
docker compose --profile subgraphs up -d lightrag-g03

# 查看状态
docker compose ps

# 停止某个分图
docker compose --profile subgraphs stop lightrag-g03
```

## 提问技巧（让 AI 回答更好）

LightRAG 综合向量检索 + 图扩展 + LLM 生成。**问具体、不空泛**回答最准：

| ❌ 效果差 | ✅ 效果好 |
|---------|----------|
| "讲讲荔枝" | "为什么杨贵妃爱吃荔枝？来自哪里？" |
| "是谁" | "谁把荔枝推荐给杨贵妃？证据是什么？" |
| "什么品种" | "挂绿荔枝为什么贵？历史拍卖记录？" |
| "在哪里" | "高州贡园的荔枝树年龄多大？哪棵最有名？" |

**用典故 / 引文提问**：AI 会尝试匹配原文段落。
**对比类问题**："杨贵妃吃的荔枝 vs 苏轼日啖三百颗的荔枝有何不同？"——会跨子图检索。

## 数据导出

### 导出子图 Cypher 查询

Neo4j Browser → 选 display 实例 → 跑 Cypher：

```cypher
// 某节点的所有邻居（限制 2 跳）
MATCH (n:g03_varieties {entity_id: '桂味'})-[r*1..2]-(m)
RETURN n, r, m LIMIT 100
```

### 导出整个子图

Neo4j Browser → 选 display → 用导出按钮（CSV / JSON / GraphML）。
